아날로그적 계약서 체결에서 광고주가 온라인으로 광고 상품을 구매하는 방식으로 전환하기 위한 신규 DSP 개발 프로젝트에 초기부터 참여. ERP 연동 자동 정산 구조를 주도하여 구축.
Problem
기존의 아날로그적 광고 판매 방식은 프로덕트 개선의 속도와 지속적 성장에 한계. 결제/정산의 수기 운영은 많은 운영 리소스와 회계적 리스크를 지님.
Solution

Result
✓ 제휴점 40% 광고센터 경험 ✓ 정산 자동화 (별도 운영인력 無) ✓ 24/7 광고 판매/구매 가능

검색광고 상품 출시
유저가 검색하는 키워드를 광고주에게 판매하여 검색결과 상단에 노출하는 검색 광고 상품 출시. 유저의 검색 경험을 저해하지 않으면서 수익을 늘리는 광고 노출 정책을 설계.
Problem
검색 지면의 지표가 우수하여 광고주 만족은 높을 것으로 예상되나, 유저의 검색 경험을 저해하지 않는 상품 기획이 필요
Solution
숙소별 구매 가능 키워드 차별화, 키워드별 유저 행동 데이터 스코어링을 통한 퀄리티 제한, 한정된 슬롯 내 균등 노출 배분으로 탐색 경험 저해 최소화
Result
✓ 트래픽 14% 성장 ✓ 이탈율 보합 유지 ✓ ROAS 1.5배 (배너 대비)
노출/판매 정책 수립 A/B 테스트 설계 데이터 기반 의사결정 TC 작성 & QA 내/외부 교육 지원

Problem
야놀자가 제공하는 상권 구분에 따른 숙소 탐색에 유저와 제휴점 모두 만족할 수 있을지 의문. 유저별 성향과 탐색 상황에 맞는 자유로운 탐색이 필요.
Solution
상권 구분 없이 지도 안에서 자유롭게 탐색할 수 있는 서비스를 만들고, 그 안에서 추가 노출 기회를 제공하는 광고 상품을 함께 기획
Result
✓ 목표 매출 10% 초과 달성 ✓ 신규 광고주 1.4배 증가 ✓ 트래픽 비중 9%로 성장
